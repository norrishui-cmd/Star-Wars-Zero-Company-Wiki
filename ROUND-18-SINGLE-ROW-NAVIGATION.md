# Round 18 — Single-row Navigation

Date: 2026-07-26

## Outcome

The English homepage desktop navigation has been consolidated from more than
twenty visible tabs into one row with eight primary controls:

1. Home
2. Database
3. Guides
4. Operations
5. Game Info
6. News
7. FAQ
8. Language

Database, Guides, Operations and Game Info are native click-to-open dropdowns.
All previously visible destinations remain available as ordinary crawlable
links inside those menus.

## Dropdown mapping

- Database: overview, Operatives, Specializations, Loadouts and Hostiles
- Guides: guide hub, Start Here, Confirmed Guides, Official Systems and Systems
- Operations: operations hub, Planner, Muster Board and The Den
- Game Info: Official Info, Story & Lore, Media, Content Map and About

Only one dropdown remains open at a time. A click outside closes the open
dropdown. At widths of 980 pixels and below, navigation changes to the existing
MENU pattern and dropdown panels become full-width stacked sections.
